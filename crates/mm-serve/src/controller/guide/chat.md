# Talking to the controller

The console is a conversation. The composer says "Ask Metamind…". Ctrl or ⌘K focuses it. A leading slash is ordinary text.

The other pane is the state board until a tool focuses a document. "Back to state" looks at the board again without a turn. The next message tells the being which pane is actually showing.

Ask how something works and the being reads the guide first. Ask for budgets, health, logs, or a memory and it calls that tool. The tool card shows the kernel's result. The document pane does not save. Asking is how a change starts, and this build does not run writes yet.

The CLI remains the headless operator. Settings and the component catalog sit under More.

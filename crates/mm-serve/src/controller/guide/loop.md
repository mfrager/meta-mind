# The autonomous loop

`loop run` walks ten stages, from experience through promotion, against a budget file. A novel goal is one no module already covers, so the loop has to build the capability.

Budgets are whole. A denial is the budget's reason. The controller does not split the work to sneak under a cap.

The CLI equivalents are `mm-cli loop run`, `mm-cli loop status`, and `mm-cli logs verify`. `loop.run` is not wired on this build.

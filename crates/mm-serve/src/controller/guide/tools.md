# Sandbox tools

Sandbox tools run inside the tool layer, not as a shell. A denial is the result. The reason names the missing grant.

Rollback restores a snapshot. A write that created a file has no snapshot and refuses. That refusal is the correct answer.

The CLI equivalents are `mm-cli tool list`, `mm-cli tool run`, `mm-cli action ledger`, and `mm-cli action rollback`. Those tools are not wired on this build.
